三种方式怎么选

直接索引文本：使用 Semdex 已有的文本、PDF、Office、压缩包和邮件解析器，速度快且不调用模型。

传入 LLM：选择下方某个 LLM 供应商；“文本内容”适合可读文件，“原始图片”适合支持视觉输入的模型。可为该扩展名单独填写 Prompt。

Python 外置插件：适合二进制格式或自定义解析。每个插件使用独立文件夹，入口固定为 plugin.py：

<插件目录>/
  my_plugin/
    plugin.py

def extract(path, ctx=None):
    return path.read_text(encoding="utf-8")

函数可以是 extract(path) 或 extract(path, ctx)，返回字符串、字节串或可转换为字符串的值；返回 None 表示没有正文。只放入可信脚本，添加后点击“重新扫描插件”。

扩展名可写 .abc 或 abc，多个用逗号分隔。同一扩展名只能出现在一条已启用规则中。

模型与运行时

三项能力互相独立，可分别使用 API 或本地模型

项目模型库

扫描项目目录中的本地模型；Semdex 不会自动下载模型。

正在读取模型目录

语义嵌入模型可从 Hugging Face 或 ModelScope 下载后放入上方目录。GGUF 直接放一个支持 embedding 的 *.gguf 文件；MLX 使用独立文件夹，保留 tokenizer 文件，并至少包含 config.json 与全部 *.safetensors 或 consolidated.* 权重。

MLX 文件夹名或 config.json 的模型信息需包含 embedding、bge、e5、nomic、gte、jina 之一，才会显示“向量”能力；文件夹相对路径就是本地模型 ID。

本地模型需要对应运行时。 MLX（mlx_lm、mlx_embeddings、mlx_vlm、mlx_whisper）仅支持 Apple Silicon Mac：退出后运行 python3 "Start Semdex.py" --with-mlx --sync-only。GGUF 文本/向量与 whisper.cpp（llama_cpp、whisper_cpp）：运行 python3 "Start Semdex.py" --with-gguf --sync-only。CTranslate2 Whisper（faster_whisper）：运行 python3 "Start Semdex.py" --with-asr --sync-only。安装完成后按平常方式重新启动；Intel Mac 和 Linux 请为图片选择支持图片输入的 OpenAI 兼容 API。

“刷新模型”重新扫描磁盘；“加载”可提前把所选用途放入内存；“卸载”释放对应运行时。未提前加载时，模型会在首次调用该用途时按需加载。
